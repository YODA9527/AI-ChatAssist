# 模块 9 — 历史记录

> 状态：**v0.7 已落地** / 优先级 P1

## 职责边界

持久化所有识别记录到 Room 数据库：
- 截图时间
- 原始 OCR 文本（脱敏后）
- 解析出的 ChatMessage 列表
- Prompt 内容
- 模型响应
- Token 用量
- 费用（按当前定价表计算）

支持**保留策略**（30 天 / 1000 条）、**手动清理**、**隐私模式不写**。

## 输入输出契约

```kotlin
@Entity(tableName = "history")
data class HistoryEntity(
    @PrimaryKey(autoGenerate = true) val id: Long = 0,
    val capturedAt: Long,
    val targetPackage: String,
    val messagesJson: String,         // ChatMessage 列表 JSON
    val promptJson: String,           // BuiltPrompt JSON
    val responseText: String,
    val promptTokens: Int,
    val completionTokens: Int,
    val totalTokens: Int,
    val cost: Double,                 // 按当时定价计算
    val chainId: Long,
)
```

## 风险点

- Room schema 迁移（v0.10 后每次升级要写 Migration）
- 大量历史记录可能影响 App 启动速度 → 列表分页
- 隐私模式切换不能清除已写入数据（需用户手动清）
