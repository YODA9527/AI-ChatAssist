# 模块 7 — 悬浮窗 UI

> 状态：**v0.1 骨架** / 优先级 P1

## 职责边界

通过 WindowManager 叠加悬浮窗：
- **触发球**（默认入口，56dp 圆形）
- **边缘触发条**（可选，16dp 窄条，替代全屏手势）
- **建议面板**（展开后显示建议回复）

负责智能贴边吸附、3 秒后半透明、复制/重新生成/关闭交互。

## 输入输出契约

```kotlin
sealed class OverlayState {
    object Collapsed : OverlayState()
    data class Expanding(val progress: Float) : OverlayState()
    data class Showing(
        val suggestions: List<String>,
        val isStreaming: Boolean,
    ) : OverlayState()
    data class Error(val message: String) : OverlayState()
}
```

## 关键类

- `OverlayController`（@Singleton）
  - `fun show()`
  - `fun hide()`
  - `fun expand()`
  - `fun collapse()`
  - `fun updateSuggestions(list: List<String>)`
  - `fun setOnCopy(callback: (String) -> Unit)`

- `TriggerBallView`（ComposeView 包装）
- `EdgeTriggerBar`（ComposeView 包装）
- `SuggestionPanel`（Compose 组件）

## 风险点

- 折叠屏展开/折叠时悬浮窗位置重置
- 不同 ROM 对悬浮窗权限名不同
- Android 12+ 通知常驻
- 全屏悬浮窗会拦截下层触摸，必须用 FLAG_NOT_TOUCH_MODAL
