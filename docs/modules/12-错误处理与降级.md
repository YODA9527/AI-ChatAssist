# 模块 12 — 错误处理与降级

> 状态：**v0.1 骨架** / 优先级 P0

## 职责边界

全局错误码定义、错误分类、降级策略、用户可见的友好提示。
**禁止静默吞错**——所有错误必须让用户知道发生了什么、能做什么。

## 输入输出契约

```kotlin
enum class ErrorCode {
    NETWORK,              // IOException
    DNS,                  // UnknownHostException
    AUTH_401,             // API Key 无效
    AUTH_403,             // 无权限
    RATE_LIMIT_429,       // 限流
    SERVER_5XX,           // 服务端异常
    TIMEOUT,              // 超时
    OCR_LOW_CONFIDENCE,   // OCR 识别率低
    PARSE_LOW_CONFIDENCE, // 解析不确定
    PERMISSION_DENIED,    // 权限被拒
    STORAGE_FULL,         // 存储满
    UNKNOWN,
}

data class AppError(
    val code: ErrorCode,
    val userMessage: String,    // 给用户看的中文
    val technicalDetail: String, // 日志里的技术细节
    val retryable: Boolean,
    val suggestedAction: SuggestedAction? = null,
)

enum class SuggestedAction { RETRY, CHECK_API_KEY, CHECK_NETWORK, OPEN_SETTINGS, CONTACT_SUPPORT }
```

## 关键类

- `ErrorClassifier` — Throwable → ErrorCode 转换
- `ErrorPresenter` — ErrorCode → 用户文案
- `FallbackStrategy` — 降级策略（如 OCR 失败时提示用户手动输入）

## 错误码表（详见 [api-contract.md §B](../api-contract.md)）

| ErrorCode | userMessage | retryable | 处理 |
|-----------|-------------|-----------|------|
| NETWORK | 请检查网络 | 是 | 指数退避重试 |
| DNS | 请检查 API URL 是否正确 | 否 | 引导改配置 |
| AUTH_401 | API Key 无效 | 否 | 引导改 Key |
| AUTH_403 | 无权限访问该模型 | 否 | 引导换模型 |
| RATE_LIMIT_429 | 请求过于频繁，已自动等待重试 | 是 | 指数退避 |
| SERVER_5XX | 模型服务异常，已重试 | 是 | 最多 3 次 |
| TIMEOUT | 模型响应超时，可重试或换模型 | 是 | 用户可手动重试 |
| OCR_LOW_CONFIDENCE | 识别不确定，请核对 | 否 | 提示用户修正 |
| PERMISSION_DENIED | 权限被拒 | 否 | 引导开启权限 |
