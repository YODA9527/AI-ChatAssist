# 模块 8 — 主界面与配置

> 状态：**v0.1 骨架** / 优先级 P0

## 职责边界

App 主入口页面（除悬浮窗外的全功能 UI）：
- **首页** — 当前状态、最近识别、快捷操作
- **设置** — API Key、模型、人设、语气、主题、省电、隐私
- **历史** — 识别记录列表与详情
- **关于** — 版本、开源许可、联系方式

通过 Compose Navigation 路由跳转。

## 输入输出契约

```kotlin
sealed class Route(val path: String) {
    object Home : Route("home")
    object Settings : Route("settings")
    object History : Route("history")
    object About : Route("about")
    object ApiConfig : Route("settings/api")
    object PersonaConfig : Route("settings/persona")
    object ThemeConfig : Route("settings/theme")
    // ... 按需扩展
}
```

## 关键类

- `MainActivity`（@AndroidEntryPoint）
  - `setContent { ChatAssistApp() }`
  - 配置 NavController + NavHost

- `ChatAssistApp`（Composable Root）
  - MaterialTheme + DynamicColor
  - NavHost 路由分发

- 各页面 ViewModel（`@HiltViewModel`）
  - `MainViewModel`
  - `SettingsViewModel`
  - `HistoryViewModel`
  - `AboutViewModel`

## 页面清单

| 页面 | 路径 | 主要功能 |
|------|------|----------|
| Home | `/home` | 状态卡片、最近识别、权限状态、快捷入口 |
| Settings | `/settings` | 设置项分类入口 |
| Settings / API | `/settings/api` | API URL / Key / Model / 链路 |
| Settings / Persona | `/settings/persona` | 双向人设编辑 |
| Settings / Tone | `/settings/tone` | 语气模板选择/编辑 |
| Settings / Theme | `/settings/theme` | 主题/动态色/字号 |
| Settings / Privacy | `/settings/privacy` | 隐私模式/清除数据 |
| History | `/history` | 识别记录列表 |
| History Detail | `/history/{id}` | 识别记录详情 |
| About | `/about` | 版本/许可/致谢 |
