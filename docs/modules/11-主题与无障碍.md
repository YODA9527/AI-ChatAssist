# 模块 11 — 主题与无障碍

> 状态：**v0.1 骨架** / 优先级 P1

## 职责边界

- **主题**：Material3 主题（Light / Dark / System）、动态取色（Dynamic Color）、高对比度、减少动效
- **无障碍**：TalkBack 兼容、触摸目标 ≥ 48dp、内容描述、字号缩放

## 输入输出契约

```kotlin
enum class ThemeMode { SYSTEM, LIGHT, DARK }
enum class DynamicColorMode { ON, OFF }  // Android 12+ 才支持
data class AccessibilitySettings(
    val highContrast: Boolean = false,
    val reduceMotion: Boolean = false,
    val fontScale: Float = 1.0f,         // 0.85 / 1.0 / 1.15 / 1.3
    val talkBackOptimized: Boolean = true,
)
```

## 关键类

- `ChatAssistTheme`（Composable）
  - `ChatAssistTheme(themeMode, dynamicColor, accessibility, content)`

- `ColorScheme`（Light + Dark + High Contrast）
