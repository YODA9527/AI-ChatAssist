# 模块 13 — 测试

> 状态：**v0.1 骨架** / 优先级 P0

## 职责边界

全链路测试覆盖：
- 单元测试（JUnit5 + MockK + Turbine）
- UI 测试（Compose UI Test）
- 截图测试（Paparazzi）
- 性能测试（Macrobenchmark）
- 端到端测试（仪器测试 + 真机）

## 测试矩阵

| 类型 | 工具 | 覆盖目标 | 目标覆盖率 |
|------|------|----------|------------|
| 单元测试 | JUnit5 + MockK | UseCase / Repository / 工具类 | ≥ 70% |
| ViewModel 测试 | Turbine + MockK | 所有 ViewModel | ≥ 80% |
| Compose UI 测试 | Compose UI Test | 关键页面 | ≥ 50% |
| 截图测试 | Paparazzi | Theme / 关键组件 | 关键路径 100% |
| 性能测试 | Macrobenchmark | 冷启动 / 热启动 / 关键路径 | 6 项 KPI |
| 仪器测试 | Espresso | 主流程 + 权限流程 | 主流程 100% |

## 测试目录

```
app/src/
├── test/                    # 单元测试（运行在 JVM）
│   ├── domain/
│   │   ├── usecase/         # 6 个 UseCase 测试
│   │   └── repository/      # Repository 测试
│   ├── data/
│   │   ├── ocr/             # OCR 解析测试（用合成 Bitmap）
│   │   ├── parser/          # 聊天解析测试（用真实截图样本）
│   │   └── llm/             # LLM 测试（用 MockWebServer）
│   └── util/                # 工具类测试
└── androidTest/             # 仪器测试（运行在设备/模拟器）
    ├── presentation/        # Compose UI 测试
    ├── capture/             # 截屏测试
    └── e2e/                 # 端到端流程
```
