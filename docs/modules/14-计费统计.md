# 14. 计费统计模块（v2.2 §13.3）

> 计费模块让哥哥「每一分钱花在哪、花多少」全透明。纯本地：计费数据只存本机 Room，绝不外传。
> 落地版本：**v0.19.0**（2026-07-19，`assembleDebug` + 全量单测 0 失败）。

---

## 14.1 职责

- 模型调用**成功/失败都记录**（成功率统计、问题排查）
- Token **精确统计**（输入/输出/cache 分别计），模型不返回 usage 时字符估算兜底
- 按**模型定价表**（用户可编辑）计算费用
- 按**日/周/月/全部**聚合（概览 + 按模型 + 按 App）
- **月度预算**阈值提醒（80% 预警 / 100% 警告 / 可选超额拦截）
- **计费 UI**：用量统计页 + 定价管理页
- **隐私**：计费数据不外传，UI 明示

## 14.4 仓储（domain/repository + data/local impl）

**`UsageRepository` 接口**：`record` / `observeAll` / `observePage` / `observeSummary(start,end)` / `observeByModel(start,end)` / `observeByApp(start,end)` / `totalCost(start,end)` / `clearAll` / `deleteOlderThan(before)`

**`PricingRepository` 接口**：`observeAll` / `get(key)` / `getByModel(model)` / `upsert` / `delete` / `resetBuiltin` / `calculateCost(usage, model): Long`

**实现要点**：
- `UsageRepositoryImpl`：Room 实体 ↔ domain 模型映射；`status` 用枚举名字符串落库
- `PricingRepositoryImpl`：**首次访问惰性 `ensureSeeded()`** 写内置定价（仅补缺）；`calculateCost` 先按 `$provider::$model` 取价（provider 由 `deriveProvider` 推导），失败按模型名兜底，都查不到返回 0（不计费、不报错）

## 14.5 计费用例（domain/usecase）

| 类 | 职责 |
|---|---|
| `CostCalculator` | **纯函数**：`costMicro = prompt/1e6*input + completion/1e6*output - cached/1e6*cachedPrice`，下限 0（防异常定价负费用） |
| `TokenCounter` | `estimate(text)`：中文 ≈1.5 字/token、英文 ≈4 字/token；`estimateUsage(prompt,response)`：模型未返回 usage 时兜底 |
| `RecordUsageUseCase` | `recordSuccess(prompt,response,targetPackage,usage)` / `recordFailure(targetPackage)`；成功但 usage 全 0 自动估算；费用计算/写库失败一律 `runCatching` 兜底，**绝不阻塞生成主链路** |
| `BudgetManager` | `currentState(): BudgetState(status,usedYuan,budgetYuan)` / `checkBudget(): BudgetStatus`；自然月 1 日 00:00 起算已用；阈值 80%/100%，超额可拦截 |
| `BudgetNotifier` | `notify(status, usedYuan, budgetYuan)`：Android 13+ 检查 `POST_NOTIFICATIONS` 权限后发预算提醒通知 |

## 14.6 集成到主流程（ReplySuggestionUseCase）

- **生成前**：读 `budgetManager.checkBudget()`，若 `EXCEEDED_BLOCK` → 直接返回预算超额错误（**必须用户可见**，不静默）
- **StreamDone（成功）**：调 `recordUsage.recordSuccess(...)` 落库 + 预算通知
- **Error（失败）**：调 `recordUsage.recordFailure(targetPackage)` 落库（status=FAILED，便于统计成功率）
- 注入：`recordUsage` / `budgetManager` / `budgetNotifier` 三依赖，`makeUseCase` 默认 `budgetManager.currentState()` 返回 `OK`
