# 模块 4 — 聊天内容解析（最核心难点）

> 状态：**v0.1 骨架** / 优先级 P0 / **难度 ★★★★★**

## 职责边界

输入 OCR 的 `List<OcrBlock>` + 目标 App 包名，输出结构化 `List<ChatMessage>`（含发送方、内容、时间戳）。
**多策略融合**判断发送方：水平位置 + 颜色聚类 + 头像位置 + 包名预设。
识别系统消息、时间戳、多气泡合并、滚动续接去重、解析置信度评分。

## 输入输出契约

```kotlin
data class ChatMessage(
    val sender: Sender,           // SELF / COUNTERPART / SYSTEM / UNKNOWN
    val content: String,
    val timestamp: Long?,
    val confidence: Float,        // 0-1，模型不确定时 < 0.7
    val rawBlocks: List<OcrBlock>,
)

enum class Sender { SELF, COUNTERPART, SYSTEM, UNKNOWN }

data class ParseResult(
    val messages: List<ChatMessage>,
    val parsedAt: Long,
    val targetPackage: String,
    val overallConfidence: Float,
)
```

## 关键类

- `ChatParserRepository`（@Singleton）
  - `suspend parse(blocks, pkg, w): Result<ParseResult>`

- `PositionClassifier` — 基于 X 坐标判断发送方
- `ColorClusterClassifier` — 基于颜色聚类（深色块=自己，浅色块=对方）
- `AppPresetProvider` — 各 App 预设规则（微信左对方右自己、钉钉相反等）
- `MessageMerger` — 多气泡合并
- `DuplicateFilter` — 滚动续接去重

## 风险点

- Flutter / 自绘 UI 的气泡可能无明显颜色或位置规律
- 极简风格 App 颜色对比度低
- 多语言混排（emoji + 中文 + 英文）
- **整个项目最难的模块，需要充分迭代**

## 设计原则

- 永远不假设 100% 准确，必须有 `confidence` 字段
- confidence < 0.7 时在 UI 上提示用户「识别不确定，请核对」
- 用户可手动修正（v0.5+ 增强）
