# 模块 04 — 聊天内容解析（最核心难点）

> 状态：**v0.10 增强** / 优先级 P0 / **难度 ★★★★★**

## 职责边界

输入 OCR 的 `List<OcrBlock>` + 目标 App 包名，输出结构化 `List<ChatMessage>`（含发送方、内容、时间戳、置信度）。
**多策略融合**判断发送方：水平位置 + App 预设（v0.10 起包名反转）+ 置信度评分。
识别系统消息、时间戳、多气泡合并、滚动续接去重、UI 模式检测（v0.10 观测，v0.11+ 动态调阈值）。

## 输入输出契约

```kotlin
data class ChatMessage(
    val id: String,
    val sender: Sender,           // SELF / COUNTERPART / SYSTEM / UNKNOWN
    val content: String,
    val timestamp: Long?,
    val confidence: Float,        // 0-1，< 0.7 UI 提示「识别不确定，请核对」
    val source: CaptureMode,      // TEXT_ONLY / OCR_ONLY
    val topY: Int = 0,            // v0.10 起：文本顶部 Y 坐标，供多气泡合并
)

data class ParseResult(
    val messages: List<ChatMessage>,
    val parsedAt: Long,
    val targetPackage: String,
    val overallConfidence: Float,
    val uiMode: UiMode = UiMode.LIGHT,  // v0.10 起：截图 UI 模式
)
```

## 关键类

- `ChatParser`（@Singleton，v0.6 起迭代至 v0.10）
  - `parse(text, centerX, screenWidth, pkg, source, index): ChatMessage`
  - v0.10 起：填 confidence（5 维加权：来源+几何+长度+位置+预设）

- `AppPreset`（v0.10，v0.10.1 精简）
  - 内置 5 个国内主流 IM：微信/QQ/钉钉/飞书/企业微信
  - `alignLeftIsSelf`：本项目内置 App 全部右侧=自己（false）

- `MessageMerger`（v0.10：C 项）
  - 同 sender + Y 距离 < 100px + 中间无时间戳 → 合并
  - topY=0 兜底：按 index 顺序 + 同 sender 合并
  - 合并后 confidence 取 min

- `MessageDeduplicator`（v0.10：D 项）
  - 5min 滑动窗口，content+sender+timestamp 哈希作指纹
  - 进程内单例 @Singleton（应用重启清空，避免长期累积误伤）
  - 用户切 App 时可调 `reset()` 主动清表

- `UiModeDetector`（v0.10：E 项，§12.2.1）
  - 64x64 缩略图 + BT.601 加权亮度
  - < 0.3 判 DARK，否则 LIGHT
  - v0.10 仅观测（写入 CaptureResult.uiMode），v0.11+ 动态调 OCR 阈值

- `PositionClassifier`（v0.6 既有）— 基于 X 坐标判断发送方
- `AppPresetProvider`（v0.10 重构为 `PRESETS` map）— 各 App 预设规则
- `MessageMerger`（v0.10）— 多气泡合并（替代 v0.6 占位）
- `DuplicateFilter`（v0.10 重构为 `MessageDeduplicator`）— 滚动续接去重

## 风险点

- 颜色聚类：ML Kit `Text.Line` 不暴露颜色、需自采样像素，开销与精度权衡不划算
- 自定义 App 预设：用户配错包名可能反向 isSelf 误判，需要 UI 提示"识别不确定"作为兜底
- 滚动去重表：进程重启清空 → 短时间内可能重复，v0.10+ 可加 Room 持久化指纹表
- 置信度评分：五维加权是经验值，v0.10 落地后用真实样本回归再微调系数

## 设计原则

- **永远不假设 100% 准确，必须有 `confidence` 字段**（v0.6 起存在，v0.10 起真算）
- **confidence < 0.7 时在 UI 上提示用户「识别不确定，请核对」**（v0.10+ UI 接入预留位）
- **宁可漏合、不可误合**（MessageMerger 三条件：同 sender + Y 距离近 + 无时间戳断点）
- **去重表不持久化**（避免长期累积的"假去重"误伤，重启清空是符合直觉的）
