# 模块 1 — 启动与权限

> 状态：**v0.1 骨架** / 优先级 P0

## 职责边界

管理 App 冷启动流程与全部运行时权限的状态机：
- 通知权限（Android 13+）
- 悬浮窗权限（`Settings.canDrawOverlays`）
- MediaProjection 权限
- 隐私政策页首次同意

负责权限申请时序、被拒降级、被撤销恢复、Android 14+ 前台服务类型声明。
**不负责**业务逻辑，仅维护权限状态并向 UI 暴露。

## 输入输出契约

```kotlin
sealed class PermissionState {
    object NotRequested : PermissionState()
    object Requesting : PermissionState()
    data class Granted(val grantedAt: Long) : PermissionState()
    data class Denied(val reason: DenyReason) : PermissionState()
    data class Revoked(val lastGrantedAt: Long) : PermissionState()
}

enum class DenyReason { USER_DENIED, SETTING_DISABLED, ROM_RESTRICTED }
data class MediaProjectionResult(val granted: Boolean, val resultCode: Int, val data: Intent?)
```

## 关键类

- `PermissionManager`（@Singleton）
  - `notificationState: StateFlow<PermissionState>`
  - `overlayState: StateFlow<PermissionState>`
  - `projectionState: StateFlow<PermissionState>`
  - `allGranted: StateFlow<Boolean>`
  - `suspend requestNotificationPermission(activity)`
  - `suspend requestOverlayPermission(activity)`
  - `suspend requestMediaProjection(activity): MediaProjectionResult`
  - `handleOnResume()` — 重新校验
  - `observeProjectionRevocation(): Flow<Unit>` — 监听系统撤销

## 风险点

- MIUI/EMUI 跳转权限页路径与 AOSP 不同
- 华为鸿蒙无 Google 服务，`Settings.canDrawOverlays` 返回值需兜底
- 用户在系统设置撤销投影后，App 端需监听 `MediaProjection#stop()` 回调
