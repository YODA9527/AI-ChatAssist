# 🏗️ Architecture Diagrams / 架构图

> 此目录存放架构图、流程图、状态机图。
> 矢量源文件 (`.drawio` / `.excalidraw` / `.svg`) 与渲染后产物 (`.png`) 都入库,方便后续编辑。

## 收录规范

| 维度 | 规范 |
|------|------|
| 源文件 | `.drawio` 或 `.excalidraw` (可编辑) |
| 渲染产物 | `.svg` 矢量 (首选) + `.png` 位图 (兼容 README) |
| 命名 | `<编号>_<主题>.svg`,例: `01_overall_architecture.svg` |
| 风格 | 单色 / 浅色 / 深色,README 引用浅色 |
