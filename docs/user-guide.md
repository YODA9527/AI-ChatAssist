# ChatAssist 用户手册

> 面向最终用户的使用手册（图文）
> 当前状态：**v0.1 骨架，UI 尚未实现**

---

## 1. 这是什么

ChatAssist 是一款**完全本地**的 Android 聊天辅助 App。
在你不擅长聊天时，它能根据当前对话内容，通过你自配的大模型 API，**实时给出回复建议**。
所有处理都在你手机上完成，**聊天内容只发往你自己配置的大模型，不经过任何第三方**。

## 2. 适用场景

- 跟喜欢的人/暧昧对象聊天，想不出怎么回
- 跟老板/客户沟通工作，怕说错话
- 跟不熟的人社交，不知道怎么开场
- 英语/日语不好，需要辅助生成外文消息
- 想保持高情商，但脑子转不过来

## 3. 不适用场景

- ❌ **不能替你发消息**——ChatAssist 只给建议，你自己选择是否发送
- ❌ **不替代真人关系**——它是辅助工具，不是社交机器人
- ❌ **不发广告、不卖数据**——我们是开源软件

## 4. 安装与配置（待 v0.2 完善）

### 4.1 安装
1. 下载 APK
2. 允许「安装来自未知来源的应用」
3. 安装

### 4.2 首次启动
1. 同意隐私政策
2. 授予通知权限（用于后台通知）
3. 授予悬浮窗权限（用于显示建议）
4. 进入 API 配置页

### 4.3 配置大模型 API
1. 进入「设置 → API 配置」
2. 填写：
   - **API URL**（如 `https://api.deepseek.com/v1`）
   - **API Key**（你从模型服务商获取的密钥）
   - **模型名**（如 `deepseek-chat`）
3. 点击「测试连接」验证配置
4. 保存

### 4.4 配置人设
1. 进入「设置 → 人设」
2. 填写：
   - **我是谁**（如：28岁产品经理）
   - **说话风格**（如：偏正式、偶尔幽默）
   - **禁忌**（如：不爆粗口、不用网络烂梗）
3. 可以为不同聊天对象（老板、暧昧对象、家人）创建多套人设

## 5. 使用流程

### 5.1 触发识别

进入任意聊天 App（微信/QQ/钉钉/飞书等），在对话界面：

- **方法 1**：点击屏幕边缘的窄条 → 双击
- **方法 2**：点击悬浮的触发球
- **方法 3**：下拉通知栏 → 点击「识别」

### 5.2 查看建议

悬浮窗会展开，显示 3 条候选回复。正在生成时会有打字机效果。

### 5.3 使用建议

- **点击建议** → 复制到剪贴板
- **长按建议** → 切换下一组建议
- **点击关闭** → 收起悬浮窗

### 5.4 切换人设

- 点击悬浮窗顶部的「人设名」→ 选择其他档案

## 6. 高级功能

### 6.1 多模态模式（智能）
- 启用后，截图会直接发给多模态模型（如 GPT-4o）
- 模型能看到表情包、图片梗、复杂布局
- 费用显著增加，建议按需开启

### 6.2 历史记录
- 所有识别记录自动保存（可关闭）
- 保留 30 天 / 最近 1000 条
- 可一键清空

### 6.3 隐私模式
- 开启后不写入任何历史记录
- 截图识别后立即清除内存
- 不缓存任何数据

## 7. 常见问题

### 7.1 配置 API Key 后还是报错
- 检查 API URL 末尾是否带 `/v1`（多数 OpenAI 兼容 API 需要）
- 检查 API Key 是否复制完整（前后不要有空格）
- 点击「测试连接」查看详细错误

### 7.2 悬浮窗不显示
- 检查是否授予了「显示在其他应用上层」权限
- 部分 ROM（小米/华为）需要在自启动管理中加白名单

### 7.3 OCR 识别率低
- 确保聊天界面是中文/英文/数字
- 表情包/颜文字/极小字号可能识别失败
- 深色模式/浅色模式都能识别，但极端对比度可能影响

### 7.4 模型回复很慢
- 检查网络状况
- 切换到「经济模式」（纯文字模型）
- 检查模型服务商是否限流
