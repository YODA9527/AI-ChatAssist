## 4. 改进路线

### 4.1 启动优化
- Baseline Profile（启动 + 关键路径热点预编译）
- 启动器 SplashScreen API
- Hilt 启动开销优化（懒加载）

### 4.2 OCR 优化
- 预热 ML Kit（App 启动时 warmUp）
- 截图降采样（仅识别必要区域）
- 异步并行（OCR + 解析可重叠）

### 4.3 模型调用优化
- 流式响应（首 token 后立即渲染）
- 请求合并（短时间内多次触发合并为 1 次）
- 本地缓存（相同消息结构命中缓存）

### 4.4 渲染优化
- 悬浮窗 Compose 懒加载
- Bitmap 复用（避免重复分配）
